这道困难题，其实不是很困难。
只要列出状态转移方程即可作答。
唯一需要注意的一点是在提交代码的时候记得释放缓存，要不然无法通过提交。
虽然仅从解答这道题的角度来看，较为容易实现（即判断两个str是否互为扰乱），但是在探索这道题的解法的过程中引申出来的一个问题值得去思考：
从宏观上来讲——是如何探索随机结果的全域解的问题，从微观上讲——是如何获取本题中给定字符串的所有扰乱解的列表的问题。

    follow_the_official_answer_revise是最终代码为了通过提交，在和官方代码进行对比优化的过程中的改进
    isScramble.py是试图在使用全域解来解决改道题
    official_answer.py是官方代码
    quanju.py是试图获取全域解的未完成代码
    Scramble.py是字符串扰乱的实现
